# Приложение A. Глоссарий терминов (EN → RU)

Термины сгруппированы по темам. В тексте книги при первом употреблении приводится
английский термин в скобках; далее используется русский вариант из этой таблицы.

## Рынок и инструменты

| Английский | Русский (в книге) | Пояснение |
|---|---|---|
| stock, share | акция | доля в капитале компании |
| common / preferred stock | обыкновенная / привилегированная акция | привилегированная ближе к облигации: фиксированный доход, приоритет выплат, обычно без голоса |
| dividend | дивиденд | часть прибыли, распределяемая акционерам |
| capital gain | прирост капитала | прибыль от продажи дороже покупки |
| security | ценная бумага | долговая (bond), долевая (equity), производная (derivative) |
| option / futures | опцион / фьючерс | право (опцион) или обязательство (фьючерс) купить/продать по заданной цене |
| buy side / sell side | buy-side / sell-side | покупатели активов (фонды) / посредники и маркет-мейкеры (инвестбанки) |
| market maker | маркет-мейкер | контрагент, обеспечивающий ликвидность, зарабатывает на спреде |
| bid / ask, spread | бид / аск, спред | лучшая цена покупки / продажи; разница между ними |
| midpoint price | средняя цена (мидпоинт) | середина спреда, бенчмарк для оценки издержек |
| limit order book | книга лимитных заявок | список всех бидов и асков |
| liquidity | ликвидность | возможность купить/продать без заметного сдвига цены |
| ETF (exchange-traded fund) | биржевой фонд (ETF) | фонд, паи которого торгуются как акции |
| index, market-cap weighted | индекс, взвешенный по капитализации | бенчмарк; вес ∝ рыночной капитализации |
| smart beta | smart beta | индексная стратегия с альтернативным взвешиванием (дивиденды, низкая волатильность, …) |
| universe | универсум (акций) | множество бумаг, с которыми работает стратегия |
| sector | сектор | отраслевая классификация акций |

## Данные и доходности

| Английский | Русский (в книге) | Пояснение |
|---|---|---|
| OHLCV | OHLCV | open, high, low, close, volume — цены открытия, максимум, минимум, закрытия, объём |
| adjusted close | скорректированная цена закрытия | цена с учётом сплитов и дивидендов |
| end-of-day (EOD) data | дневные данные (EOD) | одна запись на торговый день |
| resampling | ресемплинг | смена частоты данных (день → неделя/месяц) |
| raw / simple return | простая доходность | $P_t/P_{t-1}-1$ |
| log return | логарифмическая доходность | $\ln(P_t/P_{t-1})$ |
| lookahead return | lookahead-доходность | будущая доходность, сдвинутая к дате сигнала; используется только для оценки, не для торговли |
| forward return | форвардная доходность | то же, в терминологии Alphalens |
| overnight (close-to-open) return | ночная доходность | от закрытия до следующего открытия |
| dollar volume | долларовый объём | цена × объём; мера ликвидности |
| ADV (average daily volume) | средний дневной объём (ADV) | используется в модели издержек |
| winsorize | винзоризация | обрезка значений по заданным границам |
| outlier | выброс | аномальное наблюдение |
| stationarity | стационарность | постоянство распределения во времени |
| cointegration | коинтеграция | стационарная линейная комбинация нестационарных рядов |
| hedge ratio | коэффициент хеджирования | коэффициент в спреде парной торговли |
| spread (pairs) | спред (пары) | $s_2 - \beta s_1$ |

## Сигналы и факторы

| Английский | Русский (в книге) | Пояснение |
|---|---|---|
| trading signal | торговый сигнал | последовательность указаний long / short / ничего |
| long / short | длинная / короткая позиция | покупка / продажа без покрытия |
| momentum | моментум | «победители продолжают расти» |
| mean reversion | возврат к среднему | «отклонение возвращается к норме» |
| breakout | пробой | выход цены за границы диапазона |
| alpha factor | альфа-фактор | вектор значений по акциям, предсказывающий относительную доходность |
| risk factor | риск-фактор | общий драйвер волатильности (рынок, сектор, размер, …); известен всем и не даёт преимущества |
| factor exposure (beta, loading) | экспозиция (факторная бета) | чувствительность актива к фактору; матрица $B$ |
| factor return | факторная доходность | доходность фактора за период; вектор $f$ |
| common return | общая (факторная) доходность | $Bf$ — часть доходности, объяснённая факторами |
| specific / idiosyncratic return (risk) | специфическая (идиосинкратическая) доходность (риск) | остаток $s$; матрица $S$ |
| factor covariance matrix | ковариационная матрица факторов | $F$ |
| demean | центрирование (demean) | вычитание среднего (в т. ч. по сектору) |
| rank | ранжирование | замена значений порядковыми номерами |
| z-score | z-оценка | $(x-\mu)/\sigma$ |
| smoothing | сглаживание | скользящее среднее фактора |
| sector neutral | секторно-нейтральный | центрирован внутри каждого сектора |
| dollar neutral / market neutral | долларово-/рыночно-нейтральный | $\sum x_i = 0$ |
| leverage | плечо | $\|x\|_1 = \sum|x_i|$ |
| standardized alpha vector | стандартизованный альфа-вектор | $(\alpha-\bar\alpha)/\sum|\alpha_i|$: нейтральный, плечо 1 |
| alpha combination | комбинирование альф | объединение факторов в один сигнал |
| AI alpha | AI-альфа | сигнал, полученный ML-моделью из нескольких факторов и признаков |
| regime feature | признак рыночного режима | волатильность рынка, дисперсия доходностей и т. п. |

## Оценка факторов и стратегий

| Английский | Русский (в книге) | Пояснение |
|---|---|---|
| t-test, p-value | t-тест, p-значение | проверка $H_0$: средняя доходность = 0 |
| KS test (Kolmogorov–Smirnov) | тест Колмогорова–Смирнова | сравнение распределения с нормальным |
| ADF test | тест Дики–Фуллера (ADF) | проверка стационарности |
| Sharpe ratio | коэффициент Шарпа | $\sqrt{252}\,\bar r/\sigma_r$ для дневных данных |
| annualized return | годовая (аннуализированная) доходность | приведение к году |
| factor returns (Alphalens) | факторные доходности (Alphalens) | доходность портфеля, взвешенного по фактору |
| quantile analysis | квантильный анализ | средняя доходность по квинтилям фактора; хороший фактор монотонен |
| basis point (bp) | базисный пункт (б. п.) | 0,01 % |
| factor rank autocorrelation (FRA) | автокорреляция рангов фактора (FRA) | прокси оборачиваемости |
| turnover | оборачиваемость | объём изменений позиций |
| information coefficient (IC), rank IC | информационный коэффициент (IC) | корреляция (Спирмена) фактора с будущей доходностью |
| transfer coefficient (TC) | коэффициент переноса (TC) | корреляция альфа-вектора и фактических весов |
| tracking error | ошибка отслеживания | $\sqrt{252}\,\mathrm{std}(r_p - r_b)$ |
| drawdown | просадка | падение от локального максимума |
| out-of-sample | вне выборки | данные, не использованные при обучении |
| overfitting | оверфиттинг (переобучение) | подгонка под шум |
| lookahead bias | заглядывание в будущее | использование данных, недоступных на момент решения |
| survivorship bias | ошибка выжившего | универсум из бумаг, доживших до конца периода |

## Портфель и оптимизация

| Английский | Русский (в книге) | Пояснение |
|---|---|---|
| portfolio weights | веса портфеля | вектор $x$, доли капитала |
| holdings | позиции (holdings) | вектор $h$ в долларах |
| portfolio variance | дисперсия портфеля | $x^T \Sigma x$ |
| covariance matrix | ковариационная матрица | $\Sigma$ или $P$ |
| quadratic form | квадратичная форма | $x^T P x$ |
| convex optimization | выпуклая оптимизация | задача с выпуклой целью и ограничениями (cvxpy) |
| objective function | целевая функция | что минимизируем/максимизируем |
| constraint | ограничение | равенство/неравенство на $x$ |
| long-only | только длинные позиции | $x \ge 0$ |
| regularization | регуляризация | штраф $\lambda\|x\|_2$ за концентрацию |
| risk aversion | неприятие риска | коэффициент $\kappa$ при риске в целевой функции |
| risk cap | лимит риска | ограничение на предсказанную дисперсию |
| rebalance | ребалансировка | пересчёт весов с заданной периодичностью |
| transaction cost | транзакционные издержки | издержки на исполнение сделок |
| market impact | рыночное влияние | сдвиг цены из-за собственной сделки |
| slippage | проскальзывание | разница между ценой исполнения и бенчмарком (мидпоинтом) |
| trade list | список сделок | $h_t - h_{t-1}$ |
| PnL (profit and loss) | PnL (прибыль и убыток) | $\sum_i h_i r_i$ |
| PnL attribution | атрибуция PnL | разложение PnL по альфа-факторам, риск-факторам и издержкам |
| GMV (gross market value) | валовая стоимость позиций (GMV) | $\sum|h_i|$ |

| tokenization, stemming, lemmatization | токенизация, стемминг, лемматизация | нормализация текста |

| sentiment | тональность (сентимент) | эмоциональная окраска текста |
| readability index | индекс читабельности | сложность текста |
